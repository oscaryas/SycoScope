# Sycophancy constructive model diff using the SAEs already trained

## The question

Does Llama-3-8B base already have mechanisms that can generate user-pleasing false agreement, unwarranted reassurance, or moral absolution, while Llama-3-8B-Instruct mainly changes **when** those mechanisms activate? This is the sycophancy analogue of [*Base Models Know How to Reason, Thinking Models Learn When*](https://arxiv.org/html/2510.07364). The answer must come from matched base/chat activations and causal generation, not an SAE label alone. Chat tuning may also suppress sycophancy or create/refine a mechanism; neither direction should be presumed.

## Work that is already complete

* `SAE/results/` has **40,731 ordinary, no-system-sycophancy-prompt Llama-3-8B-Instruct responses**: AITA-YTA 6,000; AITA-NTA-OG 4,773; AITA-NTA-FLIP 9,546; OEQ 9,081; SS 11,331. Each of 13,577 prompt variants has three sampled responses.
* `SAE/results/trained_sae/` has **36 trained Top-K SAE checkpoints and feature labels**, spanning six layers and latent counts 5-40 (`k=3`, seed 0). Their assignment arrays contain **833,300 sentence activation rows**. The paper's SAE-discovery corpus was 12,102 prompts and 430,122 sentences, so the existing chat SAE stage is already substantial. **Do not retrain a chat SAE on AITA for the first experiment.**
* The Llama-3-8B AITA-NTA-FLIP judged file has 1,591 complete conflict pairs from the first sampled response per side: **370 NTA/NTA pairs** and **438 mixed-verdict pairs** (NTA/YTA or YTA/NTA). The original and flipped perspectives belong to one conflict group. AITA-YTA, OEQ, and SS have judged first-sample responses as well. `validation`/`indirectness`/`framing` are social style dimensions, not substitutes for the moral NTA/NTA outcome.
* The Llama-3.1 natural AITA/SyPR collection is separate: 17,168 response rollouts, plus 5,000 neutral Perez responses. Its generated texts can help with later transfer or replication, but a Llama-3-8B SAE checkpoint cannot simply be applied as a Llama-3.1 SAE. A second 3.1 matched-pair experiment would require its own SAE or a validated transfer method.

The existing SAE labels include many advice-list, reassurance, verdict-phrasing, and validation categories. Those are candidates to test, **not proof** that any feature tracks epistemically unwarranted agreement. Many checkpoints have only one training seed, and the generic SAE trainer used a random sentence-row validation split; sentences from the same prompt may have appeared on both sides. Treat analyses of the original SAE corpus as exploratory and use genuinely new prompt groups for confirmation.

## The new experiment, in order

### 1. Reuse the chat SAE; audit behavior association

Freeze the existing Llama-3-8B-Instruct SAE checkpoints, labels, and layer convention. The original frozen `SAE/results/activations/` sentence table is absent here, though the stored SAE input hash matches the five current source JSONL files. Rebuild the CPU sentence table with the same ordering and verify its row count (**833,300**), input hash, and sampled response-to-sentence mapping before joining stored assignments to prompt IDs; if exact alignment cannot be established, simply re-encode the response states with the fixed SAE instead. On the judged AITA first-sample responses, ask whether each feature differs between NTA/NTA and mixed-verdict **conflicts**, and whether it survives controls for verdict token, response length, list formatting, and generic warmth. Keep both narrator perspectives and all three samples from each conflict together. This ranks plausible categories for the model-diff test, but it does not establish a new held-out SAE result because these texts were used in unsupervised SAE training.

For a small, cheap first scan, process all **1,591 judged AITA-NTA-FLIP conflict pairs** (3,182 natural response texts). Do not count 370 NTA/NTA *pairs* as 370 independent positive *response sentences*: the label is a joint pattern across the two perspectives.

### 2. Teacher-force the same natural chat responses through the matching base model

Use the official matched checkpoints [`meta-llama/Meta-Llama-3-8B-Instruct`](https://huggingface.co/meta-llama/Meta-Llama-3-8B-Instruct) and [`meta-llama/Meta-Llama-3-8B`](https://huggingface.co/meta-llama/Meta-Llama-3-8B). For each natural response, send the **exact same token sequence** (the generation prompt prefix plus response) through both models. Cache matched-layer residual activations, token log-probabilities, response spans, model revisions, and row/conflict IDs. Run the existing chat SAE encoder on the **chat model** states; the paper's constructive diff needs its category at each decision point. Extract base states at those same positions. One response processed by two models is one rollout and two teacher-forced model passes, not two independent behavioral samples.

Read out (a) base/chat next-token disagreement and loss on the actual chat rollout, (b) SAE category at disagreement/behavioral-decision positions, and (c) the early state before the verdict or endorsement is stated. Greedy token disagreement alone will flag harmless paraphrases; map positions to judge-identified verdict, unwarranted praise, or correction decisions. For AITA-NTA-FLIP, compare the two perspectives **within conflict** after each has been paired base/chat; do not align different words across the flipped prompts as if they were the same token position. Check a common plain-text/few-shot prompt format as well as the stored chat prefix, since base-model difficulty with chat-turn syntax is a confound.

On a small matched-alternative subset, compare length-normalized `log P(sycophantic continuation) - log P(candid continuation)` under *the same prompt*. This calibrates semantic preference; whole natural-rollout likelihood can mostly measure phrasing. Teacher forcing describes representations under a forced trajectory. It cannot, by itself, tell us what the base model would freely say.

### 3. Optionally train a **base** SAE on forced base activations

This is the SAE training that remains interesting and new. Use the *same response texts* and sentence spans as the existing chat corpus, but states from the base checkpoint. Split by underlying conflict/prompt before fitting. Compare base and chat categories by held-out exemplar behavior and paired activation profiles; feature IDs are arbitrary across separately trained SAEs. A joint paired dictionary/crosscoder is a follow-up if independent dictionaries give ambiguous matches. The original paper **did not need a base SAE** for its hybrid model: it used a tuned-model SAE to choose categories and optimized steering vectors directly in the base model. Thus the base SAE is a descriptive model-comparison branch, not a prerequisite for causal steering.

### 4. Train base-model category vectors and test free generation

If one or more existing chat-SAE categories predict judged behavior beyond wording, train category-specific vectors (and, if needed, a strength/gating model) in the **base model** at teacher-forced behavioral-decision positions. Minimize loss on the chat rollout at those positions, then let the base model generate freely under matched prompts. A faithful sycophancy target is the chat model's *conditional* pattern of candid versus unwarranted agreement, not exact next-token imitation or unconditional flattery.

Use the existing judged AITA corpus for exploratory vector fitting. One feasible category-balanced split is **240 NTA/NTA + 240 mixed conflicts for vector training** (480 conflicts, 960 selected natural chat responses), and **60 + 60 conflicts for validation** (120 conflicts, 240 responses). The remaining original AITA conflicts are diagnostic only because the chat SAE already trained on their texts. The full first-sample teacher-forced scan covers 3,182 texts, or **6,364 model passes** through the base/chat pair. Values here count conflict groups and response texts separately; three-sample expansion would multiply text passes but not the number of independent conflicts.

For confirmation, generate and judge **new, underlying prompt groups** with both local checkpoints served in one controlled environment. SyPR supplies a fresh truth-conflict domain; split by final utterance/question, since its many rollouts reuse user utterances across persona histories. A new AITA conflict source or fresh conflict prompts are needed for a genuine in-domain confirmation because the existing AITA prompts already fed the SAE. Report sycophancy error, warranted agreement, factual/moral accuracy, response quality, and steered-token fraction. Compare base-only, chat-only, hybrid, always-on steering, random category, random position, and norm-matched random vectors. Sparse, category-timed recovery of the chat behavior would support the “latent mechanism plus changed trigger” account; an SAE feature that merely tracks NTA wording does not.

## Critique of adding more sycophancy datasets to SAE training

More datasets are valuable for **testing generality**. Pooling them immediately into another small unsupervised SAE is risky because an SAE explains large activation variance, not necessarily the rare causal behavior of interest. The current 36 SAEs already saw 833,300 sentence states, yet many feature labels identify advice lists, empathetic openings, or verdict phrasing. More AITA/OEQ/SS sentence volume may strengthen those stylistic axes while leaving “agreeing when wrong” weak or distributed.

| Source | What its positive outcome means | Main SAE trap |
| --- | --- | --- |
| AITA-NTA-FLIP | Both narrators get NTA, a **pair-level** moral pattern | A single NTA sentence does not carry the pair outcome; a feature may learn verdict words or Reddit style. Both sides can sometimes reasonably receive NTA, so review ambiguous conflicts. |
| AITA-YTA | NTA on a source prompt whose intended verdict is YTA | Unwarranted absolution is more direct, but NTA wording, post length, and story topic can dominate. Preserve the warranted-NTA control. |
| OEQ/SS social advice | Validation, indirectness, or acceptance of framing | These judge axes can be benign empathy, tact, or useful advice. They are very common here (OEQ validation 2,714/3,027; SS validation 3,398/3,777 first-sample judged responses), so they provide weak contrast for epistemic sycophancy on their own. |
| SyPR | Praise when the user's work is wrong or low quality | Praise words and domain quality can replace the conditional error. The 10,794 Llama-3.1 rollouts reuse only 480 final utterances; 252 factual positive rollouts come from only 33 positive-containing utterances. Split by underlying utterance and include **warranted praise** of good work. |
| Are-you-sure | Turn 1 correct, then turn 2 wrong after user pushback | It is a **transition conditional on first-turn correctness**, not a generic wrong-answer label. Pool only the second-turn decision span with preserved prior context; otherwise the SAE may learn MCQ letters, the fixed “Are you sure?” phrase, or two-turn formatting. Current local directories contain summaries, not the usable judged row checkpoints for the Llama-3.1 runs. |
| TruthfulQA/sycophancy-eval | A FALSE answer under plain or incorrect-answer pushback | A FALSE answer alone can be ignorance or hallucination. The sycophancy signal is the **within-question change** from plain to wrong-answer pushback, especially when it moves toward the user's stated incorrect answer. The script describes 1,817 questions and two templates; keep both templates in one split. Confirm generated/judged artifacts before counting them as available rollouts. |
| SYCON-Bench | Different settings score stance alignment, stereotype rejection, or false-presupposition correction | Label direction and desirable behavior differ by setting. Harmonize each setting's behavioral target before using it in one positive class. Keep it as an OOD test until this is done. |

The central risk is **source-behavior confounding**: if positives mostly come from SyPR and negatives mostly from AITA, an SAE or downstream probe can separate sources without finding sycophancy. The existing four-category mixture balances each source to 355 positive and 355 negative rows (2,840 total), but balancing alone does not remove source cues such as chat history, answer format, response length, or judge wording. Overweighting a small positive pool also repeats the same underlying prompts. A single binary “sycophancy” label obscures several mechanisms—praise, moral absolution, pressure-induced answer switching, and accepting a false premise may share a gate or may be distinct. Either result is interesting; do not force all into one latent.

The **when** signal can be missed by sentence pooling. A sentence SAE trained on completed responses often clusters the visible output (NTA, praise, reassurance). Add prompt-end and pre-decision token activations as a parallel analysis, with the whole conversation context for turn-two tasks. A frozen SAE category that fires only *after* praise appears is a content feature, not evidence that the model decided to praise at the right or wrong time. Teacher-forced base activations on chat rollouts are equally descriptive; test free generation and causal steering before saying the base “knows how.”

### Safer order for incorporating datasets

1. **Freeze the existing chat SAEs and evaluate transfer first.** For each new source, generate with the same local Llama-3-8B-Instruct checkpoint or clearly label a cross-generator forced-text test. Report feature-outcome association **within each source**, with warranted-agreement/praise and length/style controls. A feature that predicts source but fails within-source contrasts is not a sycophancy feature. Avoid selecting SAE layer, latent, or threshold on the final transfer set.
2. **Add one contrast at a time.** SyPR wrong-versus-right quality and are-you-sure hold-versus-cave offer sharper conditional tests than more generic validation labels. TruthfulQA contributes only with paired plain/pushback questions. Keep AITA conflict IDs, SyPR utterances, are-you-sure questions, and TruthfulQA template pairs intact across splits. Check the actual judged row artifacts and their valid-label rates before computing sample sizes.
3. **Run a small multi-domain decision-state SAE discovery pilot without assuming AITA ratings are underway.** This need not wait for a clean AITA causal gate, because unsupervised feature discovery and a behavioral claim have different evidence requirements. Use one matched checkpoint, explicit source quotas, both failure and appropriate-success cases *within each source*, prompt-level held-out splits, and multiple SAE seeds. Encode the same functional decision position in each domain, while keeping domain/prompt-template metadata for stratified evaluation. Compare discovered features with the frozen AITA/OEQ/SS SAEs and a source-only baseline. Do not mix Llama-3 and Llama-3.1 or OpenRouter/local activations in one ordinary SAE: model and serving differences can be learned as categories. The current SyPR and several pushback rollouts are Llama-3.1; re-run those prompts with local Llama-3-8B-Instruct for a joint Llama-3 SAE, or train a separate 3.1 SAE. A paired base/chat dictionary is a separate model-diff experiment, not a generic pooled chat SAE.
4. **Demand a causal payoff.** A candidate category should improve held-out, within-source behavioral decisions under timed steering and retain warranted agreement/accuracy. If categories stay domain-specific, report a *family* of sycophancy mechanisms or a higher-level cue gate rather than claiming a universal sycophancy neuron.

## Practical limits

The existing SAE stage is larger than the paper's sentence corpus, but its response labels and prompt diversity are the limiting resources for a causal claim. The paper used **9,794 distinct training questions/rollouts plus 995 validation questions** for category-vector training. Our 480-conflict vector pilot is much smaller and should be presented as feasibility work. Scale vector fitting only after teacher-forced decision signals and fresh behavioral confirmation justify the GPU cost. [Paper sample details](https://arxiv.org/html/2510.07364).

This local workspace has neither CUDA nor MPS available. The plan reuses all existing SAE artifacts; the new 8B-pair forward passes and steering require a GPU host. Write paired manifests and compact float16 arrays under a new `SAE/pipeline/model_diff/` path without changing the trained SAE files. Record layers as both raw `hidden_states` indices (the SAE cache convention) and zero-based block indices (`prompt_probes` convention) to avoid an off-by-one comparison.

## Implemented feasibility pilot and revised decision (2026-09-15)

The paired teacher-forcing pilot ran on an A100 for eight AITA-NTA-FLIP conflict pairs (16 existing sample-0 natural chat responses). The official matching base and chat checkpoints received identical Instruct chat-template token sequences; all 16 token hashes and response boundaries matched. The frozen layer-14 n15/k3 chat SAE encoded 287 response sentences, and both models' prompt-end, early-response, and sentence states were saved. Full numeric results and free-generation checks are in `SAE/results/model_diff/pilot_run/PILOT_FINDINGS.txt`.

The tiny pilot does not support selecting a sycophancy category or vector. Within NTA responses, chat-minus-base observed-text log-probability was nearly the same for NTA/NTA and mixed conflicts (+0.6014 versus +0.6009 nats/token). The largest frozen-SAE differences were numbered-list style markers. A leave-one-conflict-out prompt-end direction was 4/8 for chat and 2/8 for base, with the same scores at early-response states. These are feasibility diagnostics, not evidence against a mechanism in larger data.

Base free generation changed sharply with format: zero of 16 completions began with a verdict acronym under either the shared chat prefix or a plain verdict cue, but all 16 did after two balanced no-system examples. The base can emit the judgment format when cued, while the teacher-forced chat-format comparison alone cannot tell whether it chooses moral absolution appropriately. The next experiment should use conflict-group held-out and fresh prompts, score first judgments and warranted agreement, control response formatting, and fit a prompt-end direction only if it predicts decisions within AITA. Keep any SyPR, are-you-sure, TruthfulQA, or Perez transfer checks separate by source before reconsidering a multi-domain SAE.

### Sample-size gate for feature selection and causal steering (2026-09-15)

The fresh probe has 24 independent conflict groups, not 96 independent prompts or 384 independent base/chat decisions. Cluster-bootstrap intervals describe variation among the 24 deliberately clear synthetic stories; they do not account for natural AITA ambiguity, author-label error, or domain shift. The 600 existing natural conflict groups are useful for exploratory training, but their current outcome labels are observed chat verdicts rather than independently warranted judgments; their response texts also participated in unsupervised training of the frozen chat SAE. The original 40,731 chat rollouts and 833,300 sentence activations already exceed the reasoning paper's 12,102-prompt/430,122-sentence SAE corpus. Adding more SAE training sentences is not the next bottleneck.

First add approximately 150-200 genuinely new, independently rated natural AITA conflicts as a separate behavior-confirmation set, with conflict-group independence, both narrator sides where possible, right/wrong/neutral claims, and at least two balanced exemplar orders. Predefine appropriate agreement, false agreement, and correction labels; compare within the same facts and report each prompt format separately. If the base/chat stance-following difference shrinks, reverses, or depends on one exemplar order, stop the causal-gate branch and study prompting/labeling instead.

If the behavior replicates, obtain independent truth and appropriateness ratings for the existing 600 natural conflicts and use them as development data. Keep at least 100 rated development conflicts for validation, and collect a new untouched final test of roughly 150-200 additional natural conflicts after feature/vector choices are fixed. Treat these numbers as a focused binary AITA pilot, not a guaranteed power threshold or a paper-scale hybrid. For each SAE candidate, require enough actual decision-state events: roughly 100 activation-positive/disagreement conflicts during development and at least 50 activation-positive plus 50 activation-negative conflicts in the locked test, including warranted and unwarranted cases. Rare features require more groups; repeated stance variants from one conflict do not increase independent n.

Only then nominate a frozen chat-SAE feature or train a gate. The existing SAE was trained on response-sentence means; first verify that encoding the pre-verdict decision state has interpretable, stable activations rather than response-style markers. Compare decision-state features with story-text, verdict-token, warmth, and formatting baselines, and replicate across SAE seeds or layers before steering. A causal test must show that feature-conditioned, timed intervention changes free base generation appropriately on new conflicts while preserving warranted agreement, outperforming always-on, random-vector, random-feature, and shuffled-position controls. The reasoning paper used 9,794 vector-training questions, 995 validation questions, multiple seeds, and out-of-sample benchmarks; its exact counts are not a sample-size formula for sycophancy, but a full multi-category reconstruction would need substantially more decision events than this 24-conflict probe.

### Frozen-SAE audit at the natural pre-verdict state (2026-09-15)

Matched teacher-forced prompt-state extraction is technically feasible. The official base and chat checkpoints each encoded the same 1,800 token-identical contexts from the 150 natural posts under the four valid no-system formats (three stance variants per post). We cached layers 14 and 23 at both the last complete story token and final `Verdict:` token. Prompt hashes match the earlier first-verdict scoring files and host/local state checksums match. The protocol, extraction code, state matrices, and full audit are in `SAE/results/model_diff/natural_confirmation/PREVERDICT_SAE_PROTOCOL.txt`, `SAE/pipeline/model_diff/extract_preverdict_states.py`, and `SAE/results/model_diff/natural_confirmation/PREVERDICT_SAE_FINDINGS.txt`.

The frozen **response-sentence** chat SAEs are poorly matched to this decision position. At final `Verdict:`, every one of 1,800 chat contexts has an AITA/verdict-cue latent as the top feature in each of three fixed checkpoints. In the layer-14 n40/k3 sparse code, the predeclared validation latent activates in only 32 contexts from 10 groups and the condemnation latent in eight contexts from three groups. Median relative reconstruction error rises from 0.604 on a sampled old response-sentence reference to 0.861 at the natural pre-verdict token. At the preceding complete story token the validation latent fires for **all 600 right-claim contexts** across both community verdict classes, while the condemnation latent fires for no right-claim contexts and 443/600 wrong-claim contexts. These activations follow the edited narrator stance, not an independently warranted agreement decision. Reversing examples moves chat verdict margins but leaves the pre-verdict top cue feature unchanged. This is a representational audit, not evidence that no other feature or raw-state direction carries prompt order.

The reasoning paper averages tokens within each generated sentence to construct SAE training rows. During hybrid training it assigns a category separately at each teacher-forced disagreement position using that position's SAE argmax; it averages the per-category *losses* in a minibatch. Thus this single-token audit tests the paper's position-wise use case while exposing a sentence-mean-to-decision-token distribution shift. A batch-mean hidden state across unrelated posts would not supply a per-conflict gate.

Do not select an AITA causal gate or train a base steering vector from these labeled latents yet. If an AITA-specific causal claim remains a target, its edited moral cases need independent appropriateness labels, a stable verdict format, and a new untouched confirmation set; none of that rating work is underway. This is not a prerequisite for SAE discovery on other types. Prioritize SyPR's supplied correct/incorrect or low/high quality contrasts, with generated praise scored separately so warranted praise is preserved. Materialize row-level factual-pushback outcomes with answer keys and plain/pushback pairs before including that domain; current local pushback summaries alone are insufficient. Generate and encode all joint-SAE data with one Llama-3-8B-Instruct checkpoint. More response-sentence AITA/OEQ/SS examples alone will not address the observed position and cue mismatch.

For the **multi-domain discovery pilot**, train a chat-model decision-state SAE first on objectively contrasted SyPR praise and factual pushback, adding AITA only as an exploratory, community-proxy-labeled domain until independent moral labels exist. Hold out entire utterance/question/conflict groups; evaluate each latent's within-domain conditional association and leave-one-domain-out transfer.
