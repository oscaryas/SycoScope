Data and execution
  The 1,200-row, 4.4 MB AITA-NTA-FLIP sample-0 manifest was explicitly
  authorized for transfer to root@82.66.51.122:22933. Local and remote
  SHA-256: 615bc3469d8fa08bd1f5b5b168b69f1c7022724398e5909badb3eff6b0767300.
  The official Meta-Llama-3-8B and Meta-Llama-3-8B-Instruct checkpoints
  each processed all 1,200 observed natural chat responses. There were no
  system messages. Both passes used the same Instruct tokenizer, user-only
  chat prefix, response text, and teacher-forced token sequence. Every
  response ID, token hash, response boundary, and token count matched.
  There were 1,200 compact activation files per model. The fixed chat
  layer-14 n15/k3 SAE encoded chat response sentences; no base SAE was
  trained or used. Outputs were copied back to the workspace. Re-downloadable
  base weight shards were removed from the 32 GB host after the base output
  was verified; chat weights remain there for now.

Held-out direction test
  The main comparison fixes narrator side and observed verdict: original-
  side NTA responses from NTA/NTA versus original-NTA/flipped-YTA conflicts.
  Training conflicts: 240 positive + 206 negative = 446. Validation
  conflicts: 60 positive + 52 negative = 112, group-disjoint. All directions
  use training conflict class centroids and are evaluated once on validation.

  Validation AUC (stratified bootstrap 95% intervals):
    prompt-text TF-IDF                 0.5542 [0.4493, 0.6609]
    prompt length                      0.4583 [0.3486, 0.5645]
    base prompt-end layer-14 state     0.4413 [0.3369, 0.5508]
    chat prompt-end layer-14 state     0.5673 [0.4622, 0.6709]
    base first-32-response state       0.5756 [0.4763, 0.6776]
    chat first-32-response state       0.5369 [0.4365, 0.6427]

  Paired bootstrap AUC differences on the same validation groups:
    chat prompt-end minus base prompt-end    +0.1260 [-0.0042, 0.2590]
    chat prompt-end minus prompt-text         +0.0131 [-0.1346, 0.1609]
    base early-response minus chat early      +0.0388 [-0.0138, 0.0929]
  None of these intervals excludes zero. A prompt-end direction can encode
  story semantics or artifacts; the 0.567 chat AUC does not establish a
  conditional sycophancy gate. Early-response states have seen up to 32
  observed answer tokens, so they are also answer-style diagnostics.

Observed-response likelihood
  Mean chat-minus-base log-probability on the exact observed text is about
  +0.63 nats/token in the controlled NTA subset. The conditional difference
  between NTA/NTA and NTA/YTA is negligible: training +0.0043 [-0.0254,
  0.0310], validation -0.0005 [-0.0289, 0.0288] nats/token. This whole-
  response statistic can wash out the verdict decision and is descriptive,
  since natural responses vary in length and wording.

Interpretation and next experiment
  The larger matched pass confirms feasibility but does not yield a robust
  "base knows how; chat learns when" signature. The local frozen chat-SAE
  behavior audit was also unstable on unused conflicts and did not beat
  style cues reliably. Do not select an SAE feature for steering or pool
  extra sycophancy datasets to retrain an SAE based on these results.
  Next collect genuinely new conflict groups with warranted-agreement and
  appropriate-correction controls, fix a common verdict format for base and
  chat (the pilot showed strong format dependence), and score the first
  verdict or endorsement decision directly. Only if that decision-level
  signal survives story-text, narrator, and style controls should a base
  SAE or category-specific steering branch be scaled. A small base SAE on
  these 25,320 forced sentence states is possible as a descriptive demo,
  but cannot align feature IDs directly with the separately trained chat
  SAE and would not by itself solve the gate question.
